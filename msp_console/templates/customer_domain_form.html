Additional names (SANs)

Extra names issued as part of the SAME certificate as the domain above -- e.g. pairing a wildcard with its bare apex domain ("*.example.com" + "example.com"). Each name normally uses the Primary DNS provider selected above, but you can override that per-name if a given name lives in a different DNS zone or account -- as long as that zone's provider is also configured under DNS Providers, a single certificate can span multiple zones this way.
